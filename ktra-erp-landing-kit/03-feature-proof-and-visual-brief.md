# دليل الحقائق والتصميم البصري

## حقائق منتجية يمكن استخدامها

| المحور | الحقيقة القابلة للنشر | الفائدة التي نكتبها للعميل |
|---|---|---|
| الاستيراد | صفقة ← شحنة ← تخليص ← نقل محلي اختياري ← فاتورة دولية | متابعة سلسلة الاستيراد دون فقدان الصلة بين مراحلها. |
| التكلفة | توزيع الشحن والتخليص والنقل على بنود الصفقة مع تسوية دقيقة | تسعير قائم على تكلفة أقرب للواقع. |
| المبيعات | عروض أسعار وطلبيات وفواتير وتسليم وتحصيل | متابعة رحلة البيع بدل وثائق متفرقة. |
| المخزون | منتجات ومستودعات وحركات مخزون وأرقام تسلسلية ونقاط تجديد | معرفة الرصيد وحركته ومتى يحتاج إعادة طلب. |
| المحاسبة | قيود وشيكات وبنوك وفترات مالية وعملات وضريبة | أثر مالي واضح للعمليات وتقارير أكثر جاهزية. |
| الشركاء | عملاء وموردون وكشوف حساب وأرصدة | صورة موحدة للتعاملات والذمم. |
| المحاسب القانوني | بوابة متعددة الشركات للمراجعة والفترات الضريبية | تعاون منظم مع المحاسب دون فوضى الملفات. |
| الصلاحيات | صلاحيات وأدوار ومساحات شركات مستقلة | كل شخص يرى ما يلزمه فقط. |

## التوجيه البصري

- الاتجاه: RTL كامل، مع العربية أولاً حتى في ترتيب الأزرار والبطاقات.
- الشخصية: مهنية، هادئة، تقنية بلا ازدحام أو رسوم كرتونية عامة.
- اللون الأساسي: أزرق قريب من `#2563EB`؛ استخدم درجات السماوي والأخضر للدلالة على النجاح، والرمادي المزرق للخلفيات.
- الخلفية: بيضاء أو رمادي فاتح؛ استخدم تدرجات زرقاء رقيقة في القسم الافتتاحي فقط.
- الخط: خط عربي واضح بوزن عريض للعناوين، ونص مريح للقراءة. لا تستخدم خطاً زخرفياً.
- البطاقات: حواف مستديرة وظلال خفيفة وحدود دقيقة؛ لا تجعل كل عنصر بطاقة منفصلة بلا سبب.
- الأيقونات: بسيطة وموحّدة؛ السفينة للاستيراد، الصندوق للمخزون، الإيصال للمبيعات، الآلة الحاسبة للمحاسبة، والدرع للصلاحيات.

## قواعد استخدام اللقطات

1. لا تقصّ لقطةً بحيث تبدو بيانات العينة بيانات عميل.
2. لا تنشر أي لقطة من بيئة إنتاج أو تتضمن أسماء أو موازنات أو معلومات شخصية حقيقية قبل مراجعة المالك.
3. اترك جودة الصورة الأصلية؛ ضعها داخل إطار واجهة هادئ مع تعليق يشرح المنفعة، لا كل ما يظهر فيها.
4. إن احتجت لقطات إضافية، التقط فقط بيئة demo أو بيانات مصطنعة، وسمِّ الملفات باسم يصف الشاشة لا بتاريخ عشوائي.
5. الأولوية للقطات التي تُظهر جوهر المنتج: البيع، الشراء، المخزون، المحاسبة، ثم الاستيراد. لا تبدأ بالشيكات أو الإعدادات كصور رئيسية.
